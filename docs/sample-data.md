## Instructions

1. Open your Google Spreadsheet
2. Create tabs for each section above
3. Copy the headers (first row) into each tab
4. Copy the data rows into each tab
5. Make sure the column headers match exactly
6. Save the spreadsheet
7. Set up Google Apps Script as described in [../apps-script/README.md](../apps-script/README.md)

## Adding More Questions

Follow the same format:
- Keep QuestionID unique (ENG006, MAT006, etc.)
- Use consistent spelling for Subject names
- Set Active to TRUE to show the question
- Add clear explanations for learning value

## Tips

- Start with 20 questions per subject
- Gradually add more based on usage
- Mix difficulty levels (Easy, Medium, Hard)
- Include explanations for all answers
- Test questions before adding to production
